# DevShelf
Comunidade para desenvolvedores e gamers compartilharem cursos, ferramentas, livros, setups e reviews com sistema de pesquisa, comentários e feedbacks.

A DevShelf é uma plataforma criada para que estudantes e profissionais compartilhem avaliações, recomendações e experiências sobre ferramentas, livros, periféricos e recursos utilizados no desenvolvimento de software.
